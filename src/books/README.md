# プリロード書籍マスターデータ (Preloaded Books Master Data)

本ディレクトリ（`src/books/`）には、アプリケーション「ゆうぞら (Yuzora)」にプリロードされている書籍の青空文庫テキストファイル（Shift_JIS 形式）が格納されています。

これらのファイルは、ウェルカム画面の「開発者のオススメ」「読書家のオススメ」から選択された際に、アプリケーションによって直接読み込まれます。

## 2. 開発上の注意点 (Development Notes)

* **ファイル形式**:
  - 各テキストファイルは青空文庫の標準仕様に従い、文字コード **Shift_JIS (CP932)** でエンコードされています。
  - 改行コードは `CRLF` 形式となっています。
* **マッピングの定義**:
  - 本ファイルのデータとアプリケーションのUI表示用のメタデータ（タイトル、著者等）の紐付けは、[app.js](../js/app.js) 内の `PREDEFINED_BOOKS` 配列オブジェクトに定義されています。
* **著作権とライセンス**:
  - 本ディレクトリに含まれるすべての作品テキストは、著作者（訳者含む）の著作権保護期間が満了したパブリックドメインのコンテンツです。
