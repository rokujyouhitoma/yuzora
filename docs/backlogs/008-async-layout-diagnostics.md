# [ENH] レイアウト診断レポート生成の非同期・タイムスライス化 (ID: 008)

## 1. 概要 / Summary
デバッグコンソールから「現在のページを診断」を呼び出す `runLayoutDiagnosis` は、全段落要素に対して `getBoundingClientRect()` をループ内で呼び出すため、大規模な書籍では十数秒間画面が完全にハングアップします。
これを防ぐため、診断スキャン対象を「現在見えているページ（ビューポート）」に存在する段落のみに限定するか、あるいは `requestIdleCallback` 等を用いて 1 フレームあたり数段落ずつ時間分割（タイムスライス）してスキャンをバックグラウンド実行し、進捗を表示しながら非同期に診断レポートを生成するよう改善します。
