# [REFACTOR] CSS変数の完全活用による「CSSテーマエンジン」の導入 (ID: 041)

## 1. 概要 / Summary
現在、カラーテーマ（和紙、明、暗、漆黒など）の切り替え時に、[config.js](../../src/js/modules/config.js) などのJavaScript側でボディ要素に対して複数のスタイルクラス名を動的に追加・削除しています。これによってブラウザのCSSスタイル再計算（スタイルリフロー）がDOM全体に発生し、描画パフォーマンスに影響を与える可能性があります。

この依存関係を整理し描画パフォーマンスを改善するため、以下を実装します。
- 配色（背景色、文字色、境界線色など）をCSSカスタムプロパティ（CSS変数、例: `--theme-bg`, `--theme-fg`）として定義。
- JavaScript側のテーマ切り替えでは、ボディ要素の属性値を1つ変更する（例: `document.documentElement.dataset.theme = theme`）だけで完結させ、クラスの動的な付け替えを廃止する。
- スタイル宣言がクリーンになり、テーマ切り替え処理の実行速度と保守性が大幅に向上する。
