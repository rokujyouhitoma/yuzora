# [ENH] 目次ドロワーのキーボード・スクリーンリーダー向けアクセシビリティ向上 (ID: 013)

## 1. 概要 / Summary
現在実装されている目次（TOC）表示・ドロワー機能に対し、キーボード操作およびスクリーンリーダー（音声読み上げ技術）の完全なアクセシビリティ対応を適用します。
目次ドロワーが展開されている際、キーボードの Tab キー移動がドロワー外部の隠れた要素に流出しないようにフォーカストラップ（キーボードトラップ）を実装し、Esc キー押下でのドロワーの自動閉止に対応します。また、スクリーンリーダーの認識を制御するため、ドロワー開閉状態に合わせて `aria-expanded`、`aria-hidden`、および `aria-modal="true"` などの WAI-ARIA 属性を動的にトグル制御することで、支援技術を利用するユーザーへの読書体験を大幅に向上させます。
