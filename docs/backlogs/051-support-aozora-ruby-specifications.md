# [FEAT] 青空文庫ルビ仕様（漢字・記号判定、グループルビ、アルファベット対応）への準拠 (ID: 051)

## 1. 概要 / Summary
青空文庫の入力記述形式（注記仕様）におけるルビ表現を、パーサーで完全かつ正確に解釈しHTML（`<ruby>`タグ）にレンダリングする機能を実装します。

青空文庫のルビ仕様には以下のルールがあり、これらに正確に対応できる堅牢なトークナイザーとASTパーサーを構築します：
1. **境界マーク `｜`（または半角 `|`）によるルビ範囲特定**:
   - `｜武州｜青梅《おうめ》の宿`、`｜お伽話《フェヤリー・ストーリース》`、`｜ロンドン警視庁《スコットランドヤード》` のように、ルビをかける文字列の開始位置を正確に抽出する。
2. **漢字以外の繰り返し・特殊記号の漢字扱い**:
   - 繰り返し記号 `々` に加え、JIS X 0208外の `仝`、`〆`、`〇`、`ヶ`、および外字注記で表現する二の字点（例: `益※［＃二の字点、面区点番号1-2-22］《ますます》`）も「ルビ対象の漢字」として扱い、自動判定でルビを適用可能にする。
3. **アルファベット単語・句へのルビ（半角アキの維持）**:
   - アルファベット単語の前後に挿入される半角スペース（アキ）を維持しつつ、` Kosinski《コジンスキイ》 ` のような単一単語へのルビや、` ｜Au revoir《さらば》 ` のような複数単語へのグループルビを正しくパースする。

## 3. 実装方針 / Implementation Plan
1. **自動ルビ判定用正規表現の拡張**:
   - `tokenizeInline` での漢字マッチ用正規表現を、`々`、`仝`、`〆`、`〇`、`ヶ` および `※［＃二の字点、面区点番号1-2-22］` に対応させる。
   - 例: `/^(([一-龠々仝〆〇ヶ]|※［＃二の字点、面区点番号1-2-22］)+|[A-Za-z]+)《([^》]+)》/`
2. **`｜` マーク処理の確認**:
   - すでに実装されている `｜` もしくは `|` から `《` までの部分を無条件でルビ対象文字列として抽出するロジック（`const kanji = text.substring(i + 1, rubyEndIdx);`）が、スペースやカタカナ文字混じり（例: `Au revoir` や `釜右ヱ門`）の場合も正しく機能することを確認・保証する。

## 4. 完了条件 (DoD) / Acceptance Criteria

- [ ] `tests/unit/parser.test.js` に上記の全ルビパターンを検証する単体テストを追加し、すべて Green でパスすること。
