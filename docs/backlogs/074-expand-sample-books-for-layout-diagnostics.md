# [Enhancement] Expand Sample Books for Layout Diagnostics (ID: 074)

## 1. 概要 / Summary
青空文庫形式の多様なレイアウト記法（多重ルビ、地付き、字下げ、傍点、複数の改ページ注記）が含まれる代表的な「動作確認用サンプル書籍」を追加・統合し、パース精度および表示境界の診断結果を自動テストスイートで定量的に評価・網羅する。

## 2. 影響範囲と関連ファイル / Scope & Affected Files
- `tests/fixtures/books/` (テスト検証用サンプル書籍ファイル群)
- `tests/unit/parser.test.js` / `tests/unit/renderer.test.js` (サンプル書籍を用いたパース・描画検証テストケース)

## 3. 要件と技術的詳細 / Requirements & Technical Details
### 3.1 青空文庫フォーマットの網羅
- 特殊ルビ（アルファベット、記号混在）や、地付き・字下げが連続する詩歌のレイアウト、空行を含むテキストなど、過去に不具合が発生した、または複雑な記法を含むサンプルデータを用意する。
### 3.2 自動境界診断テストの拡充
- テストスイート内でこれらのサンプル書籍をロードし、`diagnoseBoundaryOverlap` ロジックを介してキャラクターの領域見切れやカラム重なりが検出されない（エラー数がゼロである）ことをアサートする。

## 4. 受入基準 (DoD) / Acceptance Criteria
- [ ] 複数の検証用サンプル書籍（Shift_JIS 形式）がテストリソースとして統合されていること。
- [ ] テスト実行時にすべてのサンプル書籍が正常にパース・描画され、自動診断テストで境界見切れエラーが一件も発生しないことが検証されること。
