# [ENH] デバッグ画面の拡大表示（大部分をカバーする広幅ウィンドウ化） (ID: 014)

## 1. 概要 / Summary
開発および検証時に表示される「デバッグ情報 & 操作」のウィンドウ（`#debug-modal`）について、ウィンドウとしての視覚的な質感（カード風の丸角、枠線、背景の半透明オーバーレイなど）を維持しつつ、サイズを画面の大部分（幅・高さ）を占める広さに拡張します。
これにより、デバッグ用途での操作履歴 JSON やレイアウト診断結果の一覧性と視認性を大幅に向上させます。

---

## 2. 影響範囲と関連ファイル / Scope and Affected Files
- [src/css/style.css](../../src/css/style.css)
  - `.debug-modal` スタイルの修正（最大幅を `500px` から `1200px`、最大高さを `85vh` から `90vh` 等へ拡張）
- [docs/DSN-01-high_level_design.md](../../docs/DSN-01-high_level_design.md)
  - デバッグ画面のコンポーネント構成や表示イメージ記述の更新（事前設計更新）

---

## 3. 要件と技術的アプローチ / Requirements & Technical Approach

1. **ウィンドウ風レイアウトの維持と広幅化（Large Window Modal）**:
   - `.debug-modal` の角丸（`border-radius: 16px`）や影（`box-shadow`）、背景の半透明オーバーレイ（`debug-modal-overlay`）によるウィンドウとしての美しさはそのまま残します。
   - サイズについて、幅を `90%`・最大幅を `1200px` に広げ、最大高さを `90vh` に設定して、画面の大部分を占有する広大なウィンドウへと拡張します。

2. **表示情報エリアの自動拡張**:
   - ウィンドウのサイズ拡張に伴い、`.debug-modal-body` 内にある「診断レポート表示エリア（`#diagnose-report-output`）」や「操作履歴 JSON 表示エリア（`#debug-history-json`）」がウィンドウの高さに追従して縦方向に伸びるよう、Flexbox の伸縮設定を調整します。
