# [ENH] ウェルカム画面オススメ本グリッドのローディングプレースホルダーの導入 (ID: 034)

## 1. 概要 / Summary
アプリ起動時や初期読込時の `/#/welcome` 画面において、「開発者のオススメ本」および「読書家のオススメ本」のグリッドがロードされるまでの間、空の画面や崩れたレイアウトが表示されるのを防ぎ、UX（ユーザー体験）を向上させます。
具体的には以下の実装を行います。
- **ローディング中の表現**: ロード中には、実際の書籍カードと同じサイズ・レイアウトの矩形（スケルトンスクリーン / Skeleton Placeholder）を表示し、かつパルスアニメーションなどを用いて「読込中であること」が直感的に伝わるビジュアルを表現します。
- **ロード完了後の表現**: ロードが完了した時点で、プレースホルダーから実際の書籍カードへの切り替えを行います。切り替え時にはスムーズなトランジション（例: フェードイン）を適用し、自然な表示遷移を実現します。
