# [FEATURE] 青空文庫ヘッダーフォーマットの解析と作品名・著者名の表示サポート (ID: 054)

## 1. 概要 / Summary
青空文庫形式のテキストファイル（.txt）では、ファイルの冒頭部分に書籍のメタデータ（作品名、著者名）および「【テキスト中に現れる記号について】」と呼ばれる記号解説のブロックが挿入される標準フォーマットが存在します。

現在、パーサーおよびレンダラーはこれらのヘッダー部を特別扱いしておらず、記号解説テキスト（例: `《》：ルビ` や `｜：ルビの付く文字列...`）がそのまま読書ビューア上の本文として表示されてしまっています。また、作品名と著者名が合体した形でしか保持されておらず、ビューア上の本文にも表示されません。

本機能拡張では、青空文庫の標準的なテキスト構成ルールに基づき、冒頭のヘッダー部を正しくパースし、以下の機能を提供します。
1. **メタデータ抽出**：
   - 冒頭1行目の「作品名」および2行目の「著者名」を正しく抽出し、`BookModel` の個別のプロパティ（`title` と新たに設ける `author`）に設定します。
2. **表紙ページの自動生成と表示**：
   - 本文（流し込みHTML）の先頭に、抽出した作品名と著者名を含んだ「表紙（タイトル）ページ」をHTMLとして自動生成して挿入します。
   - 生成した表紙ページの末尾には自動的に改ページ（`<div class="page-break"></div>`）を挿入し、第2ページ目から本文第1章が美しく開始されるようにします。
3. **記号解説ブロックのスキップ**：
   - 冒頭にある「【テキスト中に現れる記号について】」のブロック（水平線 `-------------------------------------------------------` で囲まれた範囲）を自動検出し、読書用の本文テキストから除外（レンダリングのスキップ）します。

## 2. 詳細仕様 / Detailed Specifications

### 2.1 ヘッダーおよび記号ブロック解析アルゴリズム
青空文庫テキストのパース開始時に、以下のステートマシンを使用してヘッダーを分解します。
- **1行目**: 作品名 (`BookModel.title` に設定。ルビ記法があれば除去)
- **2行目**: 著者名 (`BookModel.author` に設定。ルビ記法があれば除去)
- **3行目**: 空行（無視）
- **4行目以降**:
  - `-------------------------------------------------------`（半角ハイフンが多数並ぶ行）を検知した場合、次の `-------------------------------------------------------` が現れる行までのすべての行（説明文）をスキップします。
  - 記号解説ブロックを抜けた後の空行はスキップし、最初の非空行から本文としての処理を開始します。
  - 記号解説ブロックがない作品の場合、3行目の空行の後の最初の非空行から本文として処理します。

### 2.2 表紙（タイトル）ページのHTML構成
本文の先頭に以下のHTMLを動的に挿入し、上品な縦書き表紙としてスタイリングします。
```html
<div class="book-cover-page">
    <h1 class="book-cover-title">作品名</h1>
    <p class="book-cover-author">著者名</p>
</div>
<div class="page-break"></div>
```

### 2.3 CSS スタイリング
- `.book-cover-page`:
  - 縦書き（RTL/LTR）で、ページの中央〜上部に適度な余白をもって配置。
  - 書籍の雰囲気を壊さないよう、フォントサイズやマージンを調整。
- `.book-cover-title`:
  - 大きめのフォントサイズ（例: `2.5rem`）、太字（font-weight: 600）。
- `.book-cover-author`:
  - 中程度のフォントサイズ（例: `1.2rem`）、作品名から一定の間隔を空けて配置。

## 4. 完了条件 / Success Criteria (DoD)
- [ ] 青空文庫テキストファイル読込時に、記号解説ブロックが本文（レンダリング結果）から完全に除外されること。
- [ ] 読書画面の第1ページ目が表紙（作品名と著者名）として表示され、改ページを挟んで第2ページ目から本文が開始されること。
- [ ] ヘッダータイトル（画面上部）に「作品名」のみが表示されること。
- [ ] 記号解説ブロックを持たない作品（例: 記号が一切使われていない作品）でも、作品名・著者名が正しくパースされ、表紙ページが生成されること。
- [ ] ユニットテストおよびE2Eテストがすべて正常にパスすること。
