# [ENH] 見出しの直前での自動改ページ機能の追加 (ID: 062)

## 1. 概要 / Summary
「見出し（大・中・小見出し）」が表示される際、その直前の要素が別の「見出し」や「ページブレイク（改ページ要素）」ではない場合に、自動的に改ページを発生させ、見出しが新しいページ（カラム）の先頭に配置されるようにするレイアウト改善機能です。

### 検討の背景
一般の書籍において、章や節の開始を示す見出しは新ページから始まるのが標準的です。現在の仕様では、見出しの直前に明示的な `［＃改ページ］` がない限り、見出しが中途半端な位置（例えばページの最下部など）に表示されてしまう場合があり、読書の視認性とレイアウト品質を高めるために、自動的に改ページを挟む機能が求められています。

### ST (テスト担当) および SA (設計担当) の検討エリア
*   **SAの懸念点**: 
    *   すべての見出し（特に小見出しなど）の直前で一律に改ページを行うと、短いセクションが連続する場合にページ内の余白が極端に多くなり、不自然なスカスカのレイアウトになる懸念がある。
    *   大見出し・中見出しのみを対象にする、あるいは前後の文字数や残りスペースに応じて動的に制御するなどの閾値設計が必要かもしれない。
*   **STの懸念点**: 
    *   見出しと見出しの間に空行（`.empty-line`）が挟まっている場合や、連続する見出し（例：大見出しの直後に中見出しが来る構造）での二重改ページ防止ロジックが正常に機能するかどうか、多角的なテストケースによる検証が必要となる。
