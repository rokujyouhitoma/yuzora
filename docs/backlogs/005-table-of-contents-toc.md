# [FEAT] 目次表示およびジャンプ機能 (TOC) (ID: 005)

## 1. 概要 / Summary
読書画面において、書籍に含まれる見出し（大見出し・中見出し・小見出し）を抽出し、サイドドロワーから目次一覧（TOC: Table of Contents）を表示・トグルできるようにします。さらに、目次項目をクリックした際に、該当の見出し位置へ瞬時に移動するスクロールジャンプ機能を提供し、長編小説（例: 宮本武蔵）におけるナビゲーション利便性を向上させます。

### ユーザー体験の設計 (UI/UX Design)
- 設定ドロワーの隣、あるいはビューアー画面のヘッダーに「目次（TOC）」を開くトグルボタンを配置します。
- 目次ドロワーは、大見出し・中見出し・小見出しを階層インデントしてインデックス表示し、長編でも一目で構成が理解できるようにします。
- 各目次テキストからルビ記述（例: `《かんじ》`）を除去したプレーンテキストを表示し、視認性を高めます。
- 項目クリック時には、読書方向（RTL / LTR）およびウィンドウ幅に適合した正確なスクロール位置を再計算してスムーズにスクロールジャンプします。

---

## 2. 影響範囲と関連ファイル / Scope and Affected Files
- **`index.html`**: 目次ドロワー（サイドメニュー）UI、およびヘッダー・コントロールパネルへの目次表示用ボタンの追加。
- **`src/css/style.css`**: 目次ドロワーのトグルアニメーション、階層インデント表示用インデックスクラスの定義。
- **`src/js/app.js`**:
  - `parseAozoraText()` 時の見出し ID 自動付与および TOC 配列データ構築の拡張。
  - 目次ドロワー内の DOM 生成およびクリック時のジャンプ先スクロール計算ロジック（RTL/LTR スクロール同期）の実装。

---

## 3. 実装方針と技術仕様 / Implementation Plan & Technical Specs
### 3.1 パースエンジンの拡張 (`parseAozoraText`)
- 青空文庫の見出し注記 `［＃「([^」]+)」は(大|中|小)見出し］` を検出した際、見出しタグ（`<h2>`, `<h3>`, `<h4>`）に変換する処理の中で、一意の ID（例: `id="toc-heading-${index}"`）を付与する。
- 同時に、メモリ上の状態変数 `currentTOC` に見出し情報オブジェクトを格納する。
  ```javascript
  currentTOC.push({
      id: `toc-heading-${index}`,
      text: cleanHeadingText, // ルビや注記を除去したプレーンテキスト
      level: headingLevel     // 2 (大), 3 (中), 4 (小)
  });
  ```

### 3.2 縦書き・横書きに対応したスクロールジャンプロジック
- クリックされた項目の ID を用いて対象要素の `offsetLeft` を取得し、ビューアーのスクロール（RTL: 右から左、LTR: 左から右）に合わせた移動量を算出する。
- 縦書き RTL モード時、RTL の scroll-width 計算特性（ブラウザ別のマイナス方向のスクロール挙動）を考慮し、シークバー等で利用している標準計算式と同様に補正して移動位置を特定し、`readerViewport.scrollLeft` へ適用する。

## 4. 完了条件 / Success Criteria (DoD)
- [ ] コンテンツ読み込み完了時に `currentTOC` が正しく構築され、見出しタグにユニークな ID が割り当てられていること。
- [ ] 目次ドロワーのトグル表示（開閉）が滑らかに機能し、ヘッダーに配置された専用アイコンボタンから制御できること。
- [ ] 目次項目をクリックした際に、ルビ表記が除外されたプレーンテキストが表示されており、かつクリックで該当の章・節に正確にスクロールジャンプすること（RTL / LTR の両モードで動作）。
- [ ] 目次ジャンプ後、フッターのページ数表示やプログレスバー、しおり用の LocalStorage 進捗率が最新のスクロール位置と同期して自動更新されること。
