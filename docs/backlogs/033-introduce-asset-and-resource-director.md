# [REFACTOR] AssetクラスとResourceDirectorの導入によるリソース管理の抽象化 (ID: 033)

## 1. 概要 / Summary
現在、書籍（Book）などのデータやそのロード、保持、廃棄の責務が特定のモジュールに直接組み込まれているか、十分に抽象化されていません。
リソース管理を整理・効率化するため、以下の概念を導入します。
- **Asset**: リソースデータそれ自体を表現し、データ自身に関する責務（フォーマット、属性アクセスなど）を持つクラス。
- **ResourceDirector**: Assetを「リソース（Resource）」として扱い、そのロード（読み込み）、キャッシュ（保持）、および不要になったリソースのクリーンアップ（廃棄）のライフサイクル管理を担当するクラス。

具体例として、Bookデータは `BookAsset` などの具体的なAssetとして取り扱い、`ResourceDirector` がそのロード、メモリ上でのキャッシュや保持、不要になった際の廃棄をコントロールするように設計します。これにより、将来的に他のアセット（画像、フォントなど）が追加された場合にも一貫したリソース管理モデルを適用可能にします。

具体的には、以下の設計を適用します。
- [viewer.js](../../src/js/modules/viewer.js) などのコントローラ層から非同期ロードおよび状態管理ロジックを分離。
- キャッシュ・プールを内蔵し、同じアセットの重複ロードを回避。
- 不要になったアセット（シーン切り替え時など）の明示的な破棄ロジックを自動化し、メモリリークを防止。
