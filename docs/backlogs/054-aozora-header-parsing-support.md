# [FEATURE] 青空文庫ヘッダーフォーマットの解析と作品名・著者名の表示サポート (ID: 054)

## 1. 概要 / Summary
青空文庫形式のテキストファイル（.txt）および HTML ファイルでは、ファイルの冒頭部分に書籍のメタデータ（作品名、著者名）および「【テキスト中に現れる記号について】」と呼ばれる記号解説のブロックが挿入される標準フォーマットが存在します。

現在、パーサーおよびレンダラーはこれらのヘッダー部を特別扱いしておらず、記号解説テキスト（例: `《》：ルビ` や `｜：ルビの付く文字列...`）がそのまま読書ビューア上の本文として表示されてしまっています。

本機能拡張では、青空文庫の標準的なテキスト構成ルールに基づき、冒頭のヘッダー部を正しくパースし、以下の機能を提供します。
1. **メタデータ抽出**：
   - 冒頭1行目の「作品名」および2行目の「著者名」を正しく抽出し、システム内の `BookModel` に設定します。
2. **ヘッダー表示**：
   - 抽出した「作品名」「著者名」を、ビューアー内の適切な領域（例: ヘッダータイトル、本編開始前のタイトルページなど）に整形して表示します。
3. **記号解説ブロックのスキップ**：
   - 冒太にある「【テキスト中に現れる記号について】」のブロック（水平線 `---` で囲まれた範囲）を自動検出し、読書用の本文テキストから除外（レンダリングのスキップ）します。

### 青空文庫ヘッダーの構成ルール：
1. **1行目**：作品名（ルビなし）
2. **2行目**：著者名（ルビなし）
3. **3行目**：空白行（あき）
4. **4行目以降**（存在する場合のみ）：
   - `-------------------------------------------------------` (水平セパレータ。57文字前後の半角ハイフン)
   - `【テキスト中に現れる記号について】`
   - 各種記号の例示説明（作品内で実際に使用されている記号のみ列挙される）
   - `-------------------------------------------------------` (水平セパレータ)
5. **記号ブロックの後**：
   - 空白行を挟んで、本文（章タイトルや本文の第1行）が開始される。
