# [FEAT] 大容量テキストのインクリメンタル（段階的）パースおよびレンダリング (ID: 007)

## 1. 概要 / Summary
大容量（1MB以上など）の青空文庫テキストを読み込む際、数万行に及ぶ全行を一括でパース・レンダリングすることで発生するメインスレッドの数秒間の完全なハングアップ（画面フリーズ）を解消します。
テキストを数千行単位のチャンクに分割し、非同期（`requestIdleCallback` または `setTimeout`）でバックグラウンド実行します。最初の 1 チャンク目を最速でレンダリング・表示し、残りのコンテンツはユーザーが閲覧している間に非同期でインクリメンタルに追記していくことで、初期読み込み完了までの体感速度を大幅に向上させます。

また、上記に加えて、メインスレッドのフリーズをより根本的に防止するため、重いテキストデコード処理および記法パース処理自体をバックグラウンドスレッド（`Web Worker`）へオフロードする設計（非同期マルチスレッドパース）についても検証・導入します。
具体的には：
- [parser.js](../../src/js/modules/parser.js) のロジックをWorkerに移植する。
- メインスレッドとWorker間のシリアライズ・メッセージ通信によるデータフローを構築する。
