# [MNG-05] テスト仕様書 (Test Cases) - ゆうぞら (Yuzora)

本ドキュメントは、「ゆうぞら (Yuzora)」における検証計画およびテストケースを定義します。テストケースは要求仕様（[REQ-01](../requirements/REQ-01-user_requirements.md)）、システム要件（[REQ-03](../requirements/REQ-03-system_requirements.md)）、基本設計（[DSN-01](../designs/DSN-01-high_level_design.md)）、詳細設計（[DSN-02](../designs/DSN-02-low_level_design.md)）とトレーサビリティを保ち、品質を保証します。

---

## 1. テスト全体方針
本プロジェクトにおける各検証フェーズは、ITストラテジスト (ST) の設計したビジネス整合性要件を満たしているかを検証するため、独立した**検証チーム (QA / Tester)** が主導してテスト計画および実行を管理します。
* **単体検証 (QA/SC主導)**: `node --test` を使用し、JSDOMベースの仮想ブラウザ環境でコアモジュール（Parser, Router, Event, Repository, Scene）の論理的整合性を自動検証する。
* **結合・システム検証 (QA主導)**: Playwright を使用し、実ブラウザ環境でユーザー操作フロー、座標計算、ジェスチャー、および履歴同期（戻る/進む）を自動検証する。
* **実装セルフチェック (SC主導)**: コーダー自身による手動動作・表示アライメント・デバッグ診断レポートコピーの確認。
