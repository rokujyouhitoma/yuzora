# [FEAT/ENH] カラムまたぎ時の段落見切れ防止の精度向上と非同期タイムスライス処理による最適化 (ID: 083)

## 1. 概要 / Summary
`VerticalRenderer` において、カラム境界をまたぐ段落要素を検出して動的に改ページを挿入する「自己修復ループ」の精度を高めるとともに、大規模な書籍ロード時のレンダリングによるメインスレッドのブロッキング（フリーズ）を防ぐため、処理のバッチ化と非同期タイムスライス処理を導入します。

## 4. 実装方針 / Implementation Plan
Target Branch: `feat/081-082-083-page-break-improvements`

1.  **境界線またぎ判定のブレ防止 (精度向上)**:
    段落要素の `boundingBox` の左端・右端が、カラム境界（ビューポート幅の整数倍）の前後数ピクセル（例: $\pm 3$px）に位置する場合、端数計算や丸め誤差によって「1文字だけカラムをはみ出して見切れる」のを防ぐため、判定に $\pm 5$px のセーフティバッファを導入し、境界線に非常に近い文字がある場合は安全に改ページを行います。
2.  **非同期バッチ処理 (タイムスライス) の導入 (パフォーマンス最適化)**:
    `VerticalRenderer.adjustPageBreaksForOverrun` を非同期関数化（Promiseを返す）し、改ページ挿入処理の過程で `requestAnimationFrame` または `setTimeout(..., 0)` を介して定期的に制御をブラウザに返却するタイムスライス処理を実装します。これにより、書籍の読込時や設定変更時の画面フリーズを回避します。
    また、DOM挿入によるリフローの頻度を抑えるためのバッチアプローチの可能性を検証します。
