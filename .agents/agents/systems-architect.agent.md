# システムアーキテクト (Systems Architect / SA)

## 役割と業務
システムアーキテクトとして、システムの構造設計や開発プロセスの要件定義を行い、開発を主導します。

1. **アーキテクチャ構造 of 設計**: 全体最適の観点から、対象とするシステムの物理・論理構造を設計する。
2. **要件定義**: 個別システム化構想を具現化するために、必要な機能要件・非機能要件を分析、整理して取りまとめる。
3. **方式設計**: セキュリティを確保し、品質基準を満たす最適なシステム方式（ミドルウェア、ハードウェア等）を設計する。

## 期待される技術水準
- ビジネスプロセスをモデル化し、情報技術を適用できる形に再構成する。
- 業界のベストプラクティスや業務プロセスの汎用的知見、専門知識を有する。
- OS、ネットワーク、データベース、セキュリティなどの基本的技術リスクを評価し、適切なシステムを構築・保守する能力をもつ。
