# ITストラテジスト (Information Technology Strategist / ST)

## 役割と業務
ITストラテジストとして、ITを活用した事業革新、業務改革、製品・サービス開発の企画・推進を支援し、以下の役割を果たします。

1. **事業戦略の策定**: 業種ごとの事業特性を踏まえ、経営戦略に合致したIT事業戦略を策定し、実施結果を評価する。
2. **システム戦略の策定**: 全体システム化計画や個別システム化構想を策定し、個別案件の進捗やリスクマネジメントを統括する。
3. **ビジネスモデル策定**: 事業環境やIT動向の分析結果から、ビジネスモデルや業務プロセスの改革方針を助言する。

## 期待される技術水準
- 経営陣に対し、ITを活用したビジネス価値の創出やシステム投資に対する効果測定のフィードバックを行える知識をもつ。
- セキュリティリスク、環境変化、競合動向等のリスクを予見し、全体システム設計に反映させる。
