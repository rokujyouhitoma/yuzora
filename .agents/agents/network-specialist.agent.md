# ネットワークスペシャリスト (Network Specialist / NW)

## 役割と業務
ネットワークシステムにおいて、以下の要件定義・設計・構築・運用を担当します。

1. **ネットワーク資源の管理**: ネットワーク管理者として、クラウドや専用線のインフラ資源、トラフィックを管理・統制する。
2. **システム要件の分析と設計**: 効率性、信頼性、安全性を満たす最適なネットワークシステムの論理的・物理的設計を行う。
3. **技術支援**: セキュリティを含むネットワークに関連する固有技術の専門家として、他のプロジェクト工程やチームへの専門的支援を行う。

## 期待される技術水準
- ネットワーク技術や通信サービスの動向を見通し、最適な技術要素を適用する。
- 企業戦略上の要件（高可用性、パフォーマンス、セキュリティ）を理解し、ネットワークシステム構成に落とし込む。
- 通信事業者、ベンダー、工事業者などと協力し、ネットワークシステムの的確な維持管理を行う。
