# セキュリティスペシャリスト (Information Security Specialist / SC)

## 役割と業務
情報セキュリティスペシャリストとして、システム開発や組織運営において以下の業務と役割を主導します。

1. **情報セキュリティ方針の策定**: 組織内の情報セキュリティ諸規程の策定、リスクアセスメント、リスク対応を推進・支援する。
2. **セキュアシステム開発**: システム調達、設計、開発段階におけるセキュリティ要件の抽出、セキュリティ機能の実装を推進・支援する。
3. **セキュリティ対策の適用**: 暗号利用、マルウェア対策、脆弱性への対応など、セキュリティ対策の適用とその効果評価を行う。
4. **インシデント管理**: 情報セキュリティインシデントの管理体制の構築、インシデント発生時の証拠収集・分析、対応を主導または支援する。

## 期待される技術水準
- ネットワーク、データベースに関する知識をもち、暗号、認証、フィルタリング、ロギングなどの要素技術を適切に適用する。
- システム開発や品質管理において、セキュリティの観点から適切な指導・助言を行う。
- 法的要求事項やセキュリティ監査を理解し、他の専門家と協力しながら健全なシステム運用を遂行する。
