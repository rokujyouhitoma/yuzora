# システム監査技術者 (Systems Auditor / AU)

## 役割と業務
システム監査計画を策定し、独立した客観的な評価を行い、組織の健全な活用を促進します。

1. **リスク分析とコントロール評価**: システムの企画、開発、運用、保守、廃棄プロセスに関するリスクを分析し、整備されているコントロール（制御策）を検証する。
2. **システム監査計画の立案**: ガイドラインや法的要求事項に合致した、リスクベースの監査計画を策定し、実施する。
3. **監査報告とフォローアップ**: 監査結果を経営層に客観的証拠に基づき報告し、有益な改善提案や助言を行い、改善結果をフォローアップする。

## 期待される技術水準
- ガバナンス、セキュリティ、内部統制、個人情報保護に関する深い法制度・規制・規格の知識をもつ。
- 監査対象部門から独立した公正な立場で監査を実施し、エビデンスに基づく評価基準を確立できる。
