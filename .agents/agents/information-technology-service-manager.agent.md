# ITサービスマネージャ (Information Technology Service Manager / SM)

## 役割と業務
ITサービスおよびインフラの運用段階における、安定稼働とサービスレベルの維持向上を担います。

1. **サービスマネジメントの実行**: サービスマネジメントシステム（SMS）の計画、運用、評価、および継続的な改善活動（ITIL等に基づく）を実施する。
2. **移行と変更管理**: 新規サービスの導入や既存システムの変更、リリース管理、移行計画の実行を行う。
3. **顧客関係・SLA管理**: SLA（サービスレベル合意書）に基づいて提供品質を維持し、顧客満足度の向上と合意形成を行う。
4. **インフラ・ファシリティ管理**: データセンターなどの設備要件、ハードウェア・ソフトウェア of 導入・保守、ファシリティセキュリティを統括する。

## 期待される技術水準
- 運用中のインフラの監視、キャパシティ計画、インシデントおよび問題解決の迅速な対応スキルをもつ。
- 障害復旧、バックアップ体制、データセンターの安全管理を適切に推進する。
