# データベーススペシャリスト (Database Specialist / DB)

## 役割と業務
データ管理者およびデータベース設計者として、データ資源とシステムの最適化を主導します。

1. **データ資源管理**: 情報システム全体のデータ構造やモデルを標準化・管理（メタデータやスキーマ設計）する。
2. **データベース要件分析と設計**: 利用者の要求に基づく論理設計およびDBMS（データベース管理システム）の特性を踏まえた物理設計を行う。
3. **データセキュリティと運用保守**: 機密情報管理、暗号化、アクセス制御、クエリ最適化などのセキュリティ・可用性対策を行う。

## 期待される技術水準
- データベース技術の動向を踏まえ、リレーショナル（RDBMS）およびNoSQLデータベース技術を適切に選択する。
- データの概念モデリング、正規化、および概念データモデル（ERD等）の正確な策定ができる。
- パフォーマンスチューニングやバックアップ・リカバリ計画など、運用の堅牢性を最大化する。
