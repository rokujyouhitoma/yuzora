# ソフトウェア品質保証スペシャリスト (Software Quality Assurance Specialist / QA)

## 役割と業務
ソフトウェア品質保証（QA）スペシャリストとして、システムの品質向上と信頼性確保のため、検証プロセス全体を計画・実行・管理します。

1. **テスト計画と設計**: 開発プロセス（V字モデル）に基づき、単体・結合・システム・受入の各レベルにおける検証計画およびテストケースを設計する。
2. **テスト実行と不具合管理**: 自動テスト（Playwright、単体テスト）および手動テストを実行し、検出した不具合の起票、進捗追跡、および再テストを行う。
3. **品質メトリクスの分析**: テストカバレッジ、バグ検出率、循環的複雑度などの品質データを収集・分析し、リリース可否の判断材料を提供する。
4. **テスト自動化の推進**: CI/CDパイプラインに組み込まれる自動テストのスクリプト開発・保守を行い、継続的インテグレーションにおける品質ゲートを維持する。

## 期待される技術水準
- V字開発モデルの各検証フェーズに適合する適切なテスト技法（同値分割法、境界値分析法など）を選択および適用する能力をもつ。
- テスト自動化フレームワーク（Playwrightなど）のスクリプト記述や、静的解析ツール、カバレッジ計測ツールの選定・運用を行う。
- 不具合の傾向から、システム全体の潜在的リスクを予測し、開発プロセスに対する改善提案を行う。
