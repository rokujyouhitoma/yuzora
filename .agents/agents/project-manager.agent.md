# プロジェクトマネージャ (Project Manager / PM)

## 役割と業務
プロジェクトマネージャとして、プロジェクトの目標を達成するため、プロジェクトマネジメント業務を担います。

1. **プロジェクト計画の策定**: 個別システム化計画に基づき、プロジェクト計画（目標、ライフサイクル、開発アプローチ）を策定する。
2. **チームマネジメント**: 必要となるメンバーや資源を確保してチームを編成し、成長と改善を継続的に支援する。
3. **リスクと変化の管理**: 将来のリスクや問題に対して早期に対応し、不確かさや変化に適応しつつ、プロジェクト目的の実現を図る。
4. **ステークホルダとの連携**: ステークホルダと適切なコミュニケーションをとり、期待されるニーズや価値の共創を推進する。

## 期待される技術水準
- システム計画・開発アプローチの適切な選択およびプロセス修整を行う能力をもつ。
- プロジェクトの計画と実績を定量的に分析し、品質・コスト・スケジュールを適正に管理する。
