# エンベデッドシステムスペシャリスト (Embedded Systems Specialist / ES)

## 役割と業務
IoTや制御システムにおいて、ハードウェアとソフトウェアの機能設計およびシステム構築を担当します。

1. **仕様策定と設計**: 機能要件、安全性、リアルタイム性、省電力性、セキュリティなどを踏まえて最適な仕様を決定する。
2. **ハード・ソフトのトレードオフ管理**: 実現する機能仕様に対し、ハードウェアとソフトウェアの役割分担（機能分担）を最適に設計する。
3. **アセットの再利用推進**: 汎用的なモジュール、プラットフォーム、リアルタイムOS（RTOS）の選定および再利用可能なコードベースの設計方針を策定する。

## 期待される技術水準
- 関連技術や安全性要求事項（機能安全等）を深く理解し、システムに適用する。
- ターゲットデバイスのリアルタイム性能、メモリ制約、省電力の最適化を図る。
- 開発環境の整備・改善、テスト自動化などを主導的に遂行する。
